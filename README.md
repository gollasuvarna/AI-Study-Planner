# 📚 AI Study Planner

AI Study Planner is a simple web-based project designed to help students organize their study time.

## ✨ Features

- Enter the subject name
- Enter the number of study days
- Enter study hours per day
- Calculate total study hours
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Use

1. Open the project in a web browser.
2. Enter your subject name.
3. Enter the number of study days.
4. Enter the number of hours you can study each day.
5. Click the **Generate Study Plan** button.
6. View your total study hours and study plan.

## 🎯 Purpose

This project was created as a beginner-friendly web development project to practice HTML, CSS, and JavaScript.
